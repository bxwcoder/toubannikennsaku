# 最後にやった日（画面見本）

家事や消耗品の交換など「前にいつやったっけ？」を記録するアプリの画面見本です。
スマートフォンのブラウザで動きます。データはその端末のブラウザの中だけに保存されます。

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `src/App.tsx` | アプリ全体のまとめ役（データの管理と画面の切り替え） |
| `src/screens/` | 4つの画面（ホーム・登録/編集・詳細・設定） |
| `src/components/` | 画面で使う部品（カード、確認画面、お知らせなど） |
| `src/lib/date.ts` | 日付・経過日数の計算 |
| `src/lib/status.ts` | 目安の状態（余裕あり・もうすぐ・超過）と並べ替え |
| `src/lib/storage.ts` | 保存・書き出し・読み込み |
| `src/lib/templates.ts` | テンプレート（よく使う項目）の一覧 |
| `src/styles.css` | 見た目（色・大きさ） |

## 動かし方（パソコンで確認する場合）

```bash
cd last-done
npm install
npm run dev
```

## 公開用ファイルの作り方

```bash
cd last-done
npm run build
```

リポジトリ直下の `docs/` フォルダに公開用のファイルができます（GitHub Pages はここを表示します）。

## 決めた仕様

- 経過日数: 今日やった → 「今日」、昨日 → 「1日前」
- 目安を過ぎた: 目安日数ちょうど経過した日から（例: 30日の目安で30日目は「今日が目安日」、31日目は「1日超過」）
- 目安が近い: 残り3日以内
- テンプレートの目安日数は仮の値（選んだあと自由に変更できる）
