# 家紋陣取り

和風の論理パズルゲーム（Android向け・オフライン動作）。

## ルール
- 各横列・各縦列・各エリアに、家紋をちょうど1つずつ置く
- 家紋同士は斜めにも隣り合ってはいけない

## パソコンで遊ぶ（開発中の確認）
1. このフォルダで `npm install`（初回のみ）
2. `npm run dev` を実行し、表示されたアドレスをブラウザで開く

## 問題が正しいか確かめる
`npm test` … 収録されている全問題の解答が1通りであることを自動で確認します。

## 問題を作り直す・増やす
`npm run generate -- 6` … 6×6の問題集（src/game/data/puzzles-6x6.json）を自動で作ります。
解答が1通りで、推理だけで解ける問題だけが収録されます。数は tools/generate.ts の QUOTA で変えられます。
