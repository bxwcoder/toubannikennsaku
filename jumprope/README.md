# なわとびタイマー（試作版 / Phase 1）

スマホをポケットに入れて縄跳びをすると、**跳んでいる時間だけ**を自動で計測する PWA の試作版です。
大人の健康管理・ダイエット用途を想定しています。本番は React Native でネイティブ化し、サブスク収益化する計画です。

## 仕組み

加速度センサー（`DeviceMotionEvent`）の合成加速度 |a| を使います（スマホの向きに依存しない）。

1. **着地ピーク検出**：しきい値（標準 2.0g）を超える山を着地 1 回とみなす。歩行は 1.2〜1.6g 程度なので除外される
2. **リズム判定**：ピーク間隔が 0.25〜1.1 秒で 4 回連続したら「跳躍中」（判定待ちの時間もさかのぼって計上）
3. **停止判定**：1.5 秒ピークが途絶えたら「休憩」として計測停止

ロジックは `src/lib/detector.ts`（UI 非依存）にあり、ネイティブ版へそのまま移植できます。

## 機能

- 跳んだ時間・回数・テンポ（回/分）・消費カロリー目安（METs 法）
- 1 日の目標リング、連続日数、7 日間グラフ、履歴
- 音声フィードバック（計測開始 / 休憩 / 1 分ごと / 目標達成）
- ポケット用ロック画面（長押しで解除）＋ Wake Lock で画面スリープ防止
- 波形のリアルタイム表示と CSV 書き出し（しきい値チューニング用）
- デモモード（PC で疑似信号を使って動作確認）

## 使い方

```bash
npm install
npm test          # 検出ロジックのテスト（疑似信号）
npm run dev       # PC で確認（設定 → デモモードをオン）
```

### スマホで試す

モーションセンサーは **HTTPS 必須** です。

- 同じ Wi-Fi で試す：`npm run dev:https` → スマホで `https://<PCのIP>:5173` を開き、証明書の警告を許可
- もしくは `npm run build` で出力される `dist/` を Netlify / Vercel / GitHub Pages などに置く

iPhone は「はじめる」をタップしたときにモーションの許可ダイアログが出ます。

## 試作版の制約

- ブラウザの仕様上、**画面が消えると計測が止まる**ため、計測中は画面をつけたまま（ロック画面で誤タッチを防止）
- 記録は端末内（localStorage）のみ
- これらはネイティブ化（Phase 2）で解消予定
