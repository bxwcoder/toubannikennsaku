## 聞き分けの考え方（仮説・未検証）

1. **ブドウ・チェリー**：メダルがクレジットに入るとき、1枚ごとに「ピッ」と鳴る（と想定）。
   その **回数を数えれば役が分かる**（ブドウは多め、チェリーは少なめ。枚数は機種で違う）。
   音の種類を覚えさせるより、回数を数えるほうが雑音に強い可能性がある。
2. **回転数**：レバー後の「ガシャッ」という立ち上がりの音を検出。
   ジャグラーは1ゲームに最低約4.1秒かかるので、**一度数えたら約3秒は数えない**ことで二重カウントを防ぐ。
3. **隣の台対策**：スマホを置いた台の音は大きく、隣の台は小さい。音の大きさで区別する。

## 動作確認の状況

- 作り物の音（60秒）では、正解どおり「回転12回・ブドウ3回・チェリー1回・隣の台1回を除外」と判定できた。
- **本物のジャグラーの音ではまだ一度も試していません。** 上の仮説が正しいかは実録音で確認が必要です。
